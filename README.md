# Cybersecurity Threat Analysis – Power BI

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze cybersecurity threats, attack patterns, vulnerabilities, their impact, and response measures.

## 🎯 Objectives

- Analyze different types of cyber attacks
- Identify common vulnerabilities
- Understand the impact of cybersecurity incidents
- Analyze response and mitigation patterns
- Create an interactive dashboard for threat analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## 📑 Dashboard Pages

### 1. Global Threat Overview
Provides an overall view of cybersecurity threats and attack patterns using KPIs and visualizations.

### 2. Attack & Vulnerability Analysis
Analyzes different attack types, vulnerabilities, and their relationships.

### 3. Impact & Response Analysis
Analyzes the impact of attacks and the response/mitigation measures taken.

## 📈 Key Features

- Interactive filters
- KPI cards
- Data visualization
- Matrix visual
- Drill-through
- DAX measures
- Interactive dashboard navigation
